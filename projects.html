Panda Box

01 / 03

IoT · Health Tracking · Game Device

Panda Box is an IoT-based device that combines casual gaming with everyday health tracking. It reads sensor data — such as movement and activity levels — and turns that data into simple, game-like feedback, encouraging the user to stay active while having fun. The project brings together embedded programming, sensor integration, and lightweight data logic to make health tracking feel less like a chore and more like play.

DailyDish

02 / 03

Software Service · Marketplace

DailyDish is a homemade food marketplace that connects home cooks with people nearby looking for fresh, home-style meals. The platform handles listings, ordering, and coordination between cooks and customers, aiming to make it simple for anyone to turn their cooking into a small local business while giving customers access to affordable, homemade food as an alternative to restaurants.

Tic Tac Toe

03 / 03

Game

A clean, browser-based take on the classic Tic Tac Toe game, built to practice core programming logic — game state management, win-condition checking, and responsive UI interaction. Simple on the surface, it served as a solid exercise in structuring interactive front-end logic from scratch.
